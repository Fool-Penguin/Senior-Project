## 3. Caveats

1. **ChromaDB HuggingFace Embedding Model Download**: In a completely air-gapped or restricted network environment, the default ChromaDB embedding function may attempt to download `all-MiniLM-L6-v2` from Hugging Face on first run. The architecture addresses this by implementing an in-memory fallback using direct `(cwe_id, language)` lookup against `mini_test_knowledges.json`.
2. **TypeScript Grammar in Tree-sitter**: While `tree-sitter-python` and `tree-sitter-javascript` are installed in the base conda environment, `tree-sitter-typescript` can be installed via `pip install tree-sitter-typescript` (or TypeScript code parsed via JavaScript grammar for standard syntax).
3. **Delta CC Threshold**: The requirement strictly states `delta CC <= 0`. Some defense-in-depth patches (such as adding an `if not user_id: return None` guard clause) would increase CC by 1 ($\Delta CC = 1$). To strictly satisfy `delta CC <= 0`, candidate prompts must instruct the model to produce surgical parameterized replacements without introducing extra branches, or the verifier must enforce $\Delta CC \le 0$ as designed.
